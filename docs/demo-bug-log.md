## Severity Guide

| Severity | Meaning |
| --- | --- |
| Critical | Blocks login, billing, payment, room assignment, or demo continuation |
| High | Breaks an important business rule but has a workaround |
| Medium | UI/API issue that confuses the demo but does not block the main flow |
| Low | Text, layout, or minor display issue |

## Status Guide

| Status | Meaning |
| --- | --- |
| Open | Issue is recorded but not fixed |
| Reproduced | Issue was reproduced after the demo |
| Fixed | Code or data was corrected |
| Verified | Fix was verified in the demo flow |
| Deferred | Issue is intentionally moved to a later phase |
